# 兔兔花园 · Bunny Garden

面向约 8 岁儿童的双语加减法练习。纯前端运行，无账号、无后端、无运行时 AI 调用。

## 本地运行

使用 Node.js 22.16 或更新版本。

```sh
npm ci
npm run dev
```

打开终端显示的本地网址。

```sh
npm test
npm run build
npm run preview
```

`npm run standalone` 会额外生成自包含的 `standalone.html`：脚本、样式和图形全部放在一个文件里，可以直接用浏览器打开，方便先发给朋友试用。若浏览器限制本地文件保存进度，练习仍可进行；长期记录建议使用部署后的网页地址。

## 首版功能

- 简体中文 / English 随时切换。
- 15 或 20 道一轮，加法、减法或加减混合。
- 20 以内热身，以及默认的 100 以内练习；全部不进位、不退位，减法结果非负。
- 每轮生成新题，避免重复题和交换加数的等价重复；混合模式均衡安排加减法。
- 3/4 道热身、9/12 道主要练习、3/4 道复习；有历史记录时复习薄弱技能。
- 大号触摸数字键盘，也支持实体键盘数字、退格和回车。
- 首次答错可以重试，再次答错进入图解；随时可以主动查看提示或完整步骤。
- 十位条、个位圆点和三步图解；减法中划去被减掉的部分。
- 分开统计首次独立答对、再次尝试答对、获得帮助。
- 结果页逐题查看图解、额外错题复习、家长统计。
- 每完成一轮普通练习获得一朵花，6 种花循环收集；额外复习不重复奖励贴纸。
- 自动保存当前输入、答题记录、设置和近期结果；存储不可用时继续在内存中运行。
- 响应手机与横屏平板；支持减少动画、键盘焦点和模态面板焦点管理。
- 鼓励音默认关闭，可在设置开启。

## GitHub Pages 部署

1. 将此目录中的项目文件提交到专用仓库根目录，包括隐藏的 `.github` 目录和 `package-lock.json`；不要提交 `node_modules`。
2. 在 GitHub 仓库的 **Settings → Pages → Build and deployment → Source** 中选择 **GitHub Actions**。
3. 推送到 `main`，或在 Actions 中手动运行 **Check and deploy Bunny Garden**。
4. 检查工作流成功，使用部署任务输出的 GitHub Pages 链接。

仓库必须满足账户的 Pages 托管条件；GitHub Free 通常使用公开仓库。网站本身不包含儿童姓名或答题数据。

构建使用相对资源路径，可同时部署到 `https://用户名.github.io/仓库名/`、用户根站点或自定义域名，不需要手工修改仓库名。如需固定前缀，可设置 `VITE_BASE_PATH`。

`dist/` 是静态发布文件，可以托管到任何静态服务器。通过 HTTP 打开，不建议直接双击其中的 HTML 文件。

## 数据与限制

练习记录保存在当前浏览器的 localStorage 中，键为 `bunny-garden:v1`。保留最近 40 轮明细，并持续累计完成轮数和题数。清理网站数据会移除记录；无跨设备同步。共享同一个浏览器会共享练习记录，首版未提供多儿童档案。

GitHub Pages 版本首次打开需要网络。首版没有 Service Worker，不能保证断网后重新打开；当前已加载的练习不需要网络 API。自包含 HTML 版本已打包所有资源，可以离线打开。没有广告、第三方分析或外部字体。GitHub Pages 自身可能保留托管服务访问日志。

后续扩展：进位与退位、更多题型、多儿童本地档案、离线安装。

## 代码结构

- `src/engine.ts`：难度规则、随机生成、答题状态、计分、图解和存储校验。
- `src/App.tsx`：首页、练习、结果、贴纸和帮助面板。
- `src/Art.tsx`：原创 SVG 兔兔、花园和花朵。
- `src/i18n.ts`：中英界面文本。
- `src/styles.css`：响应式布局与轻量动画。
- `tests/engine.test.ts`：全题池规则检查、1,200 轮生成、图解、计分、恢复与薄弱技能复习。
- `.github/workflows/pages.yml`：检查、构建和 GitHub Pages 部署。
